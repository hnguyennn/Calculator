# Terminal-based Calculator

## Overview
A command-line calculator implemented in C++ that performs basic arithmetic. It features a memory system, allowing users to use the most recent entry in their current
expression. The user can input, at most, 20 expressions before being required to manually delete specific entries or clear all entries. 

## Objectives
- Parse user-inputted expressions from standard input and evaluate them correctly
- Implement a linked-list–based memory system to store, retrieve, and safely deallocate expressions
- Manage and properly delete memory through deallocation
- Design a clear, menu-driven command-line interface with user guidance

## Methods
- Interactive control flow using loop-based input handling
- Linked list implementation for dynamic storage of expressions/results
- Manual parsing of arithmetic operators and operands, with proper error handling for invalid inputs
- Support for reuse of the most recent entry
- Explicit memory management (node creation, deletion, and cleanup)
- Command-based CLI design (e.g., calculate, view memory, delete entries, help)
